# Numerical and Statistical Computing Assignment

This repository contains implementations of fundamental numerical methods written in **C++**.  
These programs were developed as part of an academic assignment for the subject **Numerical and Statistical Computing**.

---

## 📁 Contents

### 🔹 Root Finding Methods
- **Bisection Method** – Iterative bracketing method to find roots  
- **Regula-Falsi Method (False Position)** – Uses linear interpolation  
- **Newton-Raphson Method** – Fast converging method using derivatives  

---

### 🔹 Methods for Solving Linear Systems
- **Jacobi Method** – Uses previous iteration values  
- **Gauss-Seidel Method** – Uses updated values during iteration  
- **Gauss Elimination Method** – Direct method using elimination  

---

### 🔹 Interpolation Methods
- **Newton Forward Interpolation** – For equally spaced data (forward)  
- **Newton Backward Interpolation** – For values near the end
